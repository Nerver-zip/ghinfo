# Implement a ghinfo Milestone

You are implementing one milestone in `ghinfo`.

1. Read `/AGENTS.md`.
2. Read `/dev/PLAN.md`.
3. Read the relevant architecture/API/security/roadmap docs.
4. Read all skills relevant to the milestone.
5. Inspect current code/tests before proposing changes.
6. Restate observable acceptance criteria.
7. Implement only this milestone; avoid opportunistic architecture.
8. Add/update tests.
9. Run `./scripts/validate.sh`.
10. Report verified results, compatibility impact, risks, and deferred work.

Hard boundary: do not introduce consumer-specific behavior, a database, webhooks, GraphQL, GitHub writes, OAuth, or additional services unless the milestone explicitly requires it.
