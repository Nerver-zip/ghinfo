# Audit ghinfo

Audit the repository for:

- correctness bugs;
- stale/partial snapshot risks;
- PAT/secret exposure;
- GitHub API misuse;
- missing timeout/rate-limit handling;
- public API compatibility regressions;
- concurrency/lifetime hazards;
- unnecessary dependencies or over-engineering;
- missing tests;
- Docker/CI operational problems.

Prioritize findings by impact and reproducibility. Cite exact files/lines. Do not invent failures.
