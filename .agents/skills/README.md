# ghinfo Skills

Skills are focused procedures, not architecture documents.

Use:

- `modern-cpp` for normal implementation;
- `github-rest` for GitHub transport/parsing;
- `polling` for background refresh/state;
- `api-contract` for public endpoints/schema;
- `cpp-testing` for tests;
- `cmake-build` for build/dependencies;
- `docker` for container runtime;
- `ci-cd` for Actions;
- `cpp-code-review` before completion.

Project constraints remain canonical in `/AGENTS.md`.
